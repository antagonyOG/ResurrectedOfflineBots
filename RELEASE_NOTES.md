# v1.0.0-minimal

Initial public source release for **ResurrectedOfflineBots Minimal**.

This release contains the source and build files for:

- the Windows x64 launcher/controller
- the Resurrected AI backend DLL
- autonomous Jason AI
- visible throwing knives
- objective trap placement
- door interaction and navigation/stuck recovery
- counselor bot spawning

This GitHub source package intentionally contains **no compiled EXE/DLL files and no Friday the 13th game assets**.
