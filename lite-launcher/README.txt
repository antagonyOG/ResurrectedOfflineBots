ResurrectedOfflineBots Lite – Sandbox AI

1. Launch Friday the 13th: Resurrected.
2. Go to Offline Play → Sandbox.
3. Select any Sandbox location and settings.
4. Let the level load completely; wait until the counselor and UI are ready.
5. Run ResurrectedOfflineBots.exe.
6. Press F1 to request AI Jason.
7. Press F3 to request an AI counselor.

Keep the EXE and DLL together. They can be placed in any folder; no menu,
loose files, -NoPak option, PAK replacement, or frontend patch is required.
This Lite package is separate from the full menu/test build.
The command window stays open and shows attach and hotkey results. Spawn Jason
with F1 first; wait for the console/backend to confirm Jason is active, then
use F3 for counselors. This build includes the current Jason AI plus counselor
convergence, sweater recharge, randomized counselor class selection, and the
universal final-kill route; it does not include the full frontend/menu patch.

Important: Do not run the EXE until the Sandbox level has fully loaded.

F1 is persistent in this test build: if a selected map is still streaming the
objects needed by AI Jason, the DLL keeps the request queued and retries at a
throttled 250 ms cadence. Press F1 only once, wait for Jason to appear, and
then press F3 once per AI counselor you want to add (up to six).
